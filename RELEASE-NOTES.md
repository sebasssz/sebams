Sebams 1.8.0 adds a task reminder window when you open or return to Sebams. Configure its lead time and reference hour, preview it, open or complete a task, or snooze it for one hour.

Updates can use a shared public GitHub Releases repository. Each PC configures its own installed extension folder using SetupUpdates.cmd, connects its own Bridge and uses the same repository. Daily checks are optional; installation is triggered with Install update. Personal tasks and photos remain local.

Validation: 70 extension unit tests, 32 Bridge tests and 45 focused Chrome scenarios passed. The updater verifies every file and keeps the previous version as a backup.
