# Sebams project preferences

Repository: https://github.com/sebasssz/sebams

The user explicitly requests that completed Sebams changes always be uploaded to this GitHub repository after the relevant checks pass. Treat this as standing authorization to publish the project changes; do not ask for the same permission again.

When an extension version changes, also publish the corresponding stable GitHub Release with `Sebams.zip`, `Sebams-Bridge.zip`, and `sebams-update.json`, then verify that the updater detects it. Documentation-only changes do not require a new version or Release.

Publish project source and release assets only. Keep credentials, local connection codes, browser profiles, and personal task data private. Report any concrete publication blocker instead of claiming the upload succeeded.
