# Sebams 1.10

## Sugerencias
Abre Settings → Suggestions, escribe un título y explica la idea o el problema. Continue in GitHub abre un borrador en el repositorio sebasssz/sebams. Inicia sesión en GitHub si hace falta, revisa el texto y pulsa Create para enviarlo. El equipo puede leer y responder en Issues. La sugerencia será pública; solo se incluye el texto escrito y la versión de Sebams. No se envía ninguna tarea o foto. El borrador se conserva durante esta pestaña hasta que lo borres.

## ChatGPT para otras personas
El sitio del conector admite acceso público sin solicitar permiso al creador. Cada persona inicia sesión con su propia cuenta; las tareas se guardan separadas por el identificador de cuenta verificado por Sites. Conecta primero la extensión en Settings → ChatGPT → Connect ChatGPT.

En ChatGPT abre Plugins → + → Add custom MCP server. Usa Sebams como nombre y https://sebams-connect.poeticbadge1.chatgpt.site/mcp como URL, con autenticación OAuth. Instala la conexión y usa @Sebams. Si ya tienes el plugin instalado, puedes seguir usándolo.

La instalación y los avisos de consentimiento de ChatGPT dependen de ChatGPT y de las políticas de la cuenta. El acceso público al conector no equivale a una publicación aprobada en el directorio universal de plugins. Esa publicación requiere verificación del desarrollador y revisión de OpenAI.
